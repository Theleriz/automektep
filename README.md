# AutoMektep — Vercel-ге дайын сайт (Next.js)

Автомектепті басқару жүйесі + оқушыларға арналған сайт бір жобада:

- **Лендинг** — автошкола туралы, бағалар (15 санат), оқу жолы, нұсқаушылар, FAQ, байланыс.
- **Оқушы кабинеті** — сабақ кестесі, төлемдер, прогресс, бейнесабақтар (YouTube), 4 нұсқалы онлайн тест, әкімшімен чат, `.ics` күнтізбе, деректерді жүктеу.
- **Әкімші панелі** — басқару тақтасы, өтінімдер (CRM), хабарламалар, оқушылар, нұсқаушылар, автопарк, сабақ кестесі, теория сабақтары, емтихандар, төлемдер, жылдық жоспар, есептер, баптаулар.

Барлық бизнес-логика браузерде жұмыс істейді (`localStorage`), сондықтан сайт **толық статикалық** — сервер, дерекқор немесе ақылы қызмет қажет емес.

---

## 1. Жергілікті іске қосу

```bash
npm install
npm run dev          # http://localhost:3000
```

Стек: **Next.js 15.5.29** (static export) · React 19 · Node.js 20+ · TypeScript (тек конфигурация).
Next.js нұсқасы қауіпсіздік жаңартуларымен бекітілген (`package.json` → дәл нұсқа, `.nvmrc`).

Продакшн жинағы:

```bash
npm run build        # out/ қалтасына статикалық экспорт
npx serve out        # жинақты жергілікті тексеру
```

Талап: **Node.js 20.9+**.

## 2. Vercel-ге деплой

> Толық, қадам-қадам нұсқаулық (GitHub репозиторийі, домен, чек-лист, жиі қателер) — **[DEPLOY.md](./DEPLOY.md)**.

### А. GitHub арқылы (ұсынылады)

1. Жобаны репозиторийге жүктеңіз:
   ```bash
   cd automektep
   git init
   git add .
   git commit -m "AutoMektep 3.0 — Next.js"
   git branch -M main
   git remote add origin https://github.com/<user>/automektep.git
   git push -u origin main
   ```
2. [vercel.com/new](https://vercel.com/new) → репозиторийді таңдаңыз.
3. Барлық баптау автоматты анықталады (Framework: **Next.js**, Build: `next build`). «Deploy» басыңыз.
4. Әрі қарай әр `git push` сайтты жаңартады (preview + production).

### Б. CLI арқылы (GitHub-сыз)

```bash
npm i -g vercel
vercel login
vercel            # preview деплой
vercel --prod     # production
```

### Орта айнымалысы (міндетті емес)

| Айнымалы | Мағынасы | Мысал |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Сайттың нақты домені (canonical, OG, sitemap үшін) | `https://automektep.kz` |

Vercel: **Project → Settings → Environment Variables** → қосып, қайта деплой жасаңыз.
Доменді өзгертсеңіз — осы мәнді де жаңартыңыз.

### Домен қосу

**Settings → Domains → Add** → доменді енгізіп, DNS жазбаларын (A / CNAME) тіркеңіз. SSL сертификаты автоматты беріледі.

## 3. Жоба құрылымы

```
automektep/
├── app/
│   ├── layout.tsx          # <head>: SEO, Open Graph, JSON-LD (DrivingSchool), қаріптер
│   ├── page.tsx            # басты бет: статикалық лендинг + интерфейс қаңқасы
│   ├── globals.css         # барлық стиль (дизайн сақталған) + Next.js қабаты
│   ├── not-found.tsx       # 404 беті
│   ├── robots.ts           # /robots.txt
│   └── sitemap.ts          # /sitemap.xml
├── components/
│   ├── StaticLanding.tsx   # SEO/pre-render лендинг (JS өшірулі болса да көрінеді)
│   └── LegacyApp.tsx       # интерфейсті браузерде іске қосатын қабыршақ
├── content/site.ts         # статикалық мазмұн: санаттар, бағалар, нұсқаушылар, FAQ
├── legacy/app.js           # қосымшаның барлық логикасы (localStorage, рендер, чат)
├── public/
│   ├── fonts/              # Inter қарпі (өз хостингімізде — сыртқы сұраныс жоқ)
│   ├── favicon.svg
│   ├── og.svg              # әлеуметтік желілерге арналған 1200×630 сурет
│   └── manifest.webmanifest
├── next.config.mjs         # output: 'export' (толық статикалық)
├── vercel.json             # қауіпсіздік тақырыптары, кэш
└── package.json
```

## 4. Не өзгерді (алдыңғы бір HTML файлмен салыстырғанда)

| Бұрын | Қазір |
| --- | --- |
| Бір 294 КБ HTML (стиль + код + мазмұн аралас) | `app/`, `components/`, `legacy/`, `content/` — анық бөлінген құрылым |
| Google Fonts-тан сыртқы қаріп | Қаріп жоба ішінде (`/fonts`) — жылдам, сұранысқа тәуелсіз |
| SEO жоқ (бос `<head>`, favicon жоқ) | title/description/keywords, Open Graph, Twitter Card, JSON-LD, sitemap, robots, canonical |
| 404 беті жоқ | Жеке 404 беті |
| JS өшірулі болса — бос экран | Статикалық лендинг (толық мазмұн) + спиннер |
| Қараңғы тақырып тек қолмен | Сақталған таңдау немесе жүйелік тақырып (`prefers-color-scheme`) |
| Мобильде мәзір қатары сырғытылады, бірақ көрінбейді | Сырғыту индикаторы, «чип» жолағы, 320–380px экрандарға түзетулер |
| Кэш/қауіпсіздік тақырыптары жоқ | `vercel.json`: immutable қаріп кэші, `nosniff`, `X-Frame-Options`, `Referrer-Policy` |
| Деплой нұсқаулығы жоқ | Осы README + `vercel.json` + `.gitignore` |

| Не өзгереді | Қайда |

## 7. Шектеулер (маңызды)

Бұл — **демо/оку жобасы**, нақты өнім емес:

- Деректер тек сол браузердің `localStorage`-інде сақталады: басқа құрылғыдан кірсеңіз — деректер көрінбейді, браузер тарихын тазаласаңыз — жоғалады.
- Құпиясөздер браузерде әлсіз хэшпен (FNV-1a) сақталады — нақты пайдалануға жарамсыз.
- Рөлдер тек интерфейс деңгейінде; серверлік тексеру жоқ.

Нақты жұмысқа көшу үшін келесі қадам: дерекқор (Postgres/Supabase) + API routes + нақты аутентификация (NextAuth). Жобаның құрылымы осыған дайындалған: `legacy/app.js` функциялары (`load`, `save`, `doLogin`…) — деректер қабатын ауыстыратын жалғыз орын.

## 8. Пайдалы командалар

```bash
npm run dev      # әзірлеу сервері
npm run build    # статикалық экспорт → out/
npm run start    # (қажет емес: output: 'export' режимінде)
```

Статикалық жинақты кез келген хостингке (Netlify, Cloudflare Pages, GitHub Pages, S3) жүктеуге болады — `out/` қалтасын тапсырыңыз.
